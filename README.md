**My AI Coding Tools Setup Project**

This project documents the installation and setup process of Cursor IDE, Claude Code, and Codex extensions, along with GitHub repository creation, and troubleshooting some setup issues.

**Tools Installed**

This project involved setting up and using several tools for AI-assisted coding and version control:
> Cursor IDE - An AI-powered code editor used for software development and project management.
> Claude Code Extension — An AI coding assistant integrated into Cursor to help with coding tasks and project workflows.
> Codex Extension — An AI development tool used to assist with code generation and automation.
> GitHub — A platform used to create and manage the public repository for version control and project sharing.

**Steps to Install and Activate**

1. Install Cursor IDE 
   - Visit Cursor at https://cursor.com/ and download the installer.
   - Open the downloaded .exe file. Follow the setup wizard, accept the license terms, and choose your preferred installation directory.
   - Create or sign into a Cursor account to access the AI features.

2. Install Claude Code Extension in Cursor
   - Open Cursor and navigate to the Extensions panel on the left sidebar (File > Preferences > Extensions).
   - Type "Claude Code" in the search bar. Look for the official extension published by Anthropic and click install.
   - Log in to Claude Code via the link display in Cursor (claude.com/claude-code).

3. Install Codex Extension in Cursor
   - Open Cursor and navigate to the Extensions view by clicking the square icon on the left sidebar.
   - Search for "Codex" or "Codex – OpenAI’s coding agent" in the marketplace. Select the extension and click install.
   - Once installed, you will be prompted to sign in with your ChatGPT account to activate the features.

4. Create a public GitHub repository
   - Create a GitHub account at https://github.com/
   - Log in to your account and click the "+" icon in the top-right corner.
   - Select "New repository" from the dropdown menu to open the setup page.
   - Repository Name: Enter a short, memorable name. 
   - Choose visibility as "Public" to ensure anyone on the internet can see your repository.
    
5. Open the repository in Cursor
   - Open Cursor and ensure the left-hand sidebar is visible (use Ctrl + B to toggle).
   - Click on the "Source Control" icon and the "Clone Repository" button in the sidebar.
   - Choose "Clone from GitHub".
   - Once prompted, sign in to your GitHub account and authorize Cursor (one-time code can be found in the bottom-left corner of the Cursor).
   - Select a local destination folder on your computer where the files will be saved.
   - Click "Open" when the cloning process finishes to start working.

6. Create a README.md file
   - Open GitHub and navigate to your repository.
   - Click Add file > Create new file.
   - Name the file "README.md".
   - Describe the project title, description, tools to install, step-by-step instructions, issues and solutions to complete the installation.

7. Commit and push to GitHub
   - After created the content in README.md file, click "Commit changes" box.
   - Confirm the changes by clicking Commit changes.
